# CLAUDE.md — правила проекта для AI-ассистентов

Этот файл читают AI-ассистенты (Claude, Cursor и т.д.) при работе с репозиторием. Правила ниже нужно соблюдать автоматически, без напоминаний от пользователя.

---

## 🗺️ Главное правило: карта сайта

**Любая новая HTML-страница в корне репозитория обязана попасть в `sitemap.html`.**

Карта сайта — это один файл: [`sitemap.html`](sitemap.html). Он лежит в корне, открывается в браузере, группирует все страницы по категориям.

### Когда обновлять `sitemap.html`

Запускать генератор **каждый раз**, когда:

- ✅ Создаётся новая HTML-страница в корне
- ✅ Удаляется или переименовывается страница в корне
- ✅ Меняется `<title>` страницы, который уже попал в карту
- ✅ Меняется принадлежность страницы к группе (например, архивируешь лендинг)

### Как обновлять

Запусти из корня репозитория:

```bash
python3 .claude/build_sitemap.py
```

Скрипт:
1. Автоматически обнаруживает все `*.html` файлы в корне (кроме `_menu.html`, `_footer.html`, `404.html`, самого `sitemap.html`)
2. Вытаскивает `<title>` каждой страницы
3. Для блог-постов (`tpost-*.html`) классифицирует их как «статью» или «кейс» по `.claude/blog_data/all_posts.json`
4. Для остальных страниц использует ручной словарь `MANUAL` в скрипте
5. Новые страницы без явной классификации попадают в группу «📄 Прочее» — их оттуда нужно вручную переместить в нужную группу

### Как добавить страницу в правильную группу

Открой `.claude/build_sitemap.py`, найди словарь `MANUAL` и добавь туда новую страницу:

```python
MANUAL = {
    ...
    "мой-новый-лендинг.html": ("funnel", 40, "Мой новый лендинг"),
    #                            ^группа  ^порядок  ^человеко-читаемое название
    ...
}
```

**Доступные группы:**

| ключ | Название | Для чего |
|---|---|---|
| `funnel` | 🎯 Воронка | Квиз → видео → продукт |
| `main` | 🏠 Основные информационные | То, что в главном меню |
| `forms` | 📝 Формы и заявки | Формы записи на консультации |
| `numerology` | 🔮 Нумерология | Нумерологические лендинги |
| `webinars` | 🎤 Вебинары и благодарности | Прошедшие вебинары и спасибо-страницы |
| `blog_articles` | 📝 Блог — Записки психолога | Статьи (tpost-* автоматически) |
| `blog_cases` | 💼 Блог — Кейсы пересборки | Кейсы (tpost-* автоматически) |
| `legal` | ⚖️ Юридические документы | Оферты, политики, согласия |
| `legacy` | 🗄️ Архив / Legacy | Старые страницы для обратной совместимости |

Если нужна новая группа — добавь её в массив `GROUPS` в том же файле.

### После обновления скрипта — обязательно

```bash
python3 .claude/build_sitemap.py    # перегенерировать sitemap.html
git add sitemap.html .claude/build_sitemap.py
git commit -m "..."
```

## Другие полезные скрипты в `.claude/`

| Скрипт | Что делает | Когда запускать |
|---|---|---|
| `build_sitemap.py` | Генерирует `sitemap.html` | После любого изменения набора страниц |
| `build_blog.py` | Генерирует превью-карточки блога и обрабатывает посты | Если обновляются посты блога из Tilda API |
| `fetch_blog.py` | Скачивает посты с живого janeotabaeva.ru | Если в Tilda добавились новые статьи/кейсы |
| `detildify.py` | Убирает ссылки на Tilda CDN из HTML | Обычно одноразово, но полезно перезапускать после добавления новых Tilda-экспортов |
| `fix_images.py` | Чинит коллизии имён картинок | Одноразово (фикс бага) |
| `fix_chrome.py` | Инжектит header/footer в страницы | Если добавлена новая Tilda-страница без единого header/footer |
| `fix_footer.py` | Заменяет футер на канонический (с юр-ссылками) | Если содержимое `_footer.html` изменилось |

## Технический стек сайта

- **Хостинг:** GitHub Pages (main branch, репо `alexotabaev/JaneOtabaeva`)
- **Домен:** `janeotabaeva.ru` (подключён через custom domain в Settings → Pages)
- **Сборка:** отсутствует — всё статично, `*.html` файлы в корне
- **Шрифты:** Lora (заголовки) + Noto Sans (основной текст) + Cormorant Garamond (кастомный лендинг 5prichin)
- **Палитра:** `#faf5f5` (фон), `#7a5858` / `#8c6868` (тёмно-коричневый акцент), `#3a2e2a` (текст)
- **Исходные Tilda-ассеты** самохостятся в папках `css/`, `js/`, `images/`, `files/`, `images/cdn/`

## Правила стиля и подхода

1. **Не используй Tilda CDN** — все ссылки должны быть локальными. Если добавляется новый Tilda-экспорт, прогони `detildify.py`.
2. **Не добавляй `data-tilda-*` атрибуты** на элементы — они триггерят ошибку «Tilda is configured for another domain».
3. **Не трогай `_menu.html` и `_footer.html`** — это исходники переиспользуемых блоков. Если надо обновить меню/футер глобально — правь их, потом запусти `fix_chrome.py` / `fix_footer.py`.
4. **Юр-ссылки обязательны в футере** каждой страницы (кроме `_menu.html`, `_footer.html`, `404.html`). Если создаёшь новую страницу — убедись, что в ней есть блок `<!--footer-->...<!--/footer-->` с 4 юр-ссылками.
5. **Не ломай адаптивность** — проверяй на экранах от 320px до 1440px.
6. **Не оставляй `janeotabaeva.ru` в `href`** внутренних ссылок — только относительные `*.html`.
